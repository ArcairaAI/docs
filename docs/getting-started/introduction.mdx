# ARCAIRA Wiki

ARCAIRA is a platform for creating and talking to AI characters that can remember important details from your conversations over time.

This wiki explains how to create better characters, understand how character fields work, and follow ARCAIRA's community rules.

## Start here

If you're creating a character, read:

- [Character Creation Guidelines](/guides/character-creation-guidelines)
- [Community Guidelines](/policies/community-guidelines)

## Character creation

When creating a character, ARCAIRA gives you separate fields for:

- Personality
- Backstory
- Scenario
- Starting Message

Each field has a different purpose. Keeping them clear and focused helps the character behave more consistently.

The Character Creation Guidelines explain how to use each field properly, how to write clear character information, and how to use supported tags such as `{{user}}`.

## Community rules

Characters and content shared on ARCAIRA must follow the Community Guidelines.

These rules cover things such as:

- Character images
- Sexual content
- Harmful content
- Privacy
- Impersonation
- Public character content
